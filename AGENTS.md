# Project instructions

- This project uses the local Python virtual environment at `.venv`.
- On Windows PowerShell, always run Python with `.\.venv\Scripts\python.exe`.
- Install packages with `.\.venv\Scripts\python.exe -m pip install ...`.
- Do not use global `python`, Microsoft Store Python, or WindowsApps Python.
- Before running code, verify the interpreter with:
  `.\.venv\Scripts\python.exe -c "import sys; print(sys.executable)"`
