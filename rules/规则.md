# 一、深蹲 Squat 规则表

IPF 规则要求运动员取杠后后退建立起始姿势。运动员必须在身体静止、基本直立、膝盖锁定后，等待主裁给出 “Squat” 口令。运动员下蹲时，髋关节处大腿上表面要低于膝盖上表面。运动员随后要站回直立锁膝姿势，并等待 “Rack” 口令。([powerlifting.sport][1])

| rule_id                | 动作 | IPF 规则含义                    | 失败条件                      | 自动化等级  | Codex 判断思路                                                             |
| ---------------------- | -- | --------------------------- | ------------------------- | ------ | ---------------------------------------------------------------------- |
| SQ_START_SIGNAL        | 深蹲 | 运动员必须等主裁 “Squat” 口令后开始下蹲    | 运动员在口令前解锁膝盖并开始下蹲          | 需要音频   | 识别音频中的 “Squat” 时间点。再检测膝角开始变小的时间。如果膝角变化早于口令，则 fail                      |
| SQ_START_UPRIGHT       | 深蹲 | 起始姿势要基本直立                   | 起始时躯干明显没有直立               | 可自动判断  | 在 lift_start_frame 前，计算肩、髋、膝的相对位置。躯干角度偏差过大则 uncertain 或 fail           |
| SQ_START_KNEES_LOCKED  | 深蹲 | 起始时膝盖要锁定                    | 起始时膝角明显弯曲                 | 可自动判断  | 计算左右膝角。若膝角低于锁膝阈值，例如 160°，则 fail。阈值要用数据集校准                              |
| SQ_DEPTH               | 深蹲 | 最低点时，髋关节处大腿上表面要低于膝盖上表面      | 髋点没有低于膝点                  | 可自动判断  | 找 bottom_frame。比较 hip_y 和 knee_y。注意图像 y 轴向下为正。侧面视频更可靠                  |
| SQ_ONE_DESCENT         | 深蹲 | 只允许一次下降尝试                   | 下蹲过程中出现明显停止后再次下降，或多次尝试找深度 | 可自动判断  | 用杠铃高度或髋点高度曲线分段。若下降阶段出现多次局部最低点，则 fail 或 uncertain                       |
| SQ_DOUBLE_BOUNCE       | 深蹲 | 底部不能双弹                      | 底部出现二次弹震                  | 可自动判断  | 在 bottom_frame 附近分析髋点和杠铃高度。若出现“上升一点又下降”的局部波动，且幅度超过阈值，则 fail            |
| SQ_BAR_DOWNWARD_ASCENT | 深蹲 | 上升过程中不能有任何下沉                | 上升阶段杠铃整体出现向下移动            | 可自动判断  | 从 bottom_frame 到 lockout_frame 取 bar_y 曲线。若 bar_y 增大超过阈值，说明杠铃下沉，则 fail |
| SQ_FINISH_UPRIGHT      | 深蹲 | 完成时要站回直立                    | 完成时没有站直                   | 可自动判断  | 在 lockout_frame 计算躯干角度和髋膝相对位置。明显前倾或未伸髋则 fail/uncertain                 |
| SQ_FINISH_KNEES_LOCKED | 深蹲 | 完成时膝盖要锁定                    | 完成时膝角明显弯曲                 | 可自动判断  | 计算 lockout_frame 的左右膝角。低于阈值则 fail                                      |
| SQ_RACK_SIGNAL         | 深蹲 | 运动员必须等 “Rack” 口令后回架         | 运动员在 Rack 口令前主动回架         | 需要音频   | 识别 “Rack” 时间点。检测杠铃向架子方向移动或身体明显前移时间。如果早于口令，则 fail                       |
| SQ_FOOT_MOVEMENT       | 深蹲 | 脚不能前后移动，也不能横向移动。脚掌和脚跟之间摇动允许 | 下蹲开始后、Rack 口令前，脚发生前后或左右位移 | 需要多角度  | 跟踪左右脚关键点。单侧只能看前后移动。正面更适合看横向移动                                          |
| SQ_SPOTTER_CONTACT     | 深蹲 | 口令之间保护员不能接触杠铃或运动员来帮助完成动作    | 保护员接触杠铃或运动员，并且这个接触帮助了动作   | 只能人工判断 | 可以用目标检测找接触，但“是否帮助完成动作”很主观。系统最多标记 possible_spotter_contact              |
| SQ_ELBOW_LEG_CONTACT   | 深蹲 | 肘或上臂不能支撑腿部。轻微接触可以允许         | 肘或上臂压在腿上并形成支撑             | 需要多角度  | 检测肘点、上臂区域和大腿区域是否重叠。是否“支撑”很难判断，应输出 uncertain                            |
| SQ_DROP_BAR            | 深蹲 | 完成后不能丢杠或抛杠                  | 完成后运动员主动丢弃杠铃              | 可自动判断  | Rack 后检测杠铃快速下落或脱离运动员控制。实际比赛中也要看现场，应保守判断                                |
| SQ_GENERAL_COMPLIANCE  | 深蹲 | 必须符合深蹲动作描述中的所有要求            | 出现规则表外但违反动作描述的问题          | 只能人工判断 | 保留人工复核入口。系统不要硬判                                                        |

# 二、卧推 Bench Press 规则表

IPF 规则要求运动员仰卧在凳上，头、肩、臀要接触凳面，双脚要平放在地面。运动员取杠后，要在肘锁定、杠铃静止后等待 “Start” 口令。运动员下放杠铃到胸部或腹部区域，并让杠铃静止。主裁给出 “Press” 口令后，运动员把杠铃推到双肘锁定，然后等待 “Rack” 口令。IPF 规则还要求杠铃到底部时，双侧肘关节下侧要降到各自肩关节上表面同高或更低。([powerlifting.sport][1])

| rule_id                        | 动作 | IPF 规则含义                     | 失败条件             | 自动化等级  | Codex 判断思路                                             |
| ------------------------------ | -- | ---------------------------- | ---------------- | ------ | ------------------------------------------------------ |
| BP_SETUP_HEAD_CONTACT          | 卧推 | 头部要接触卧推凳                     | 头部离开凳面           | 需要多角度  | 检测头部关键点和凳面区域。单个正面视频难判断接触关系                             |
| BP_SETUP_SHOULDER_CONTACT      | 卧推 | 双肩要接触卧推凳                     | 肩部离开凳面           | 需要多角度  | 侧面或斜侧面检测肩点与凳面距离。遮挡严重时输出 uncertain                      |
| BP_SETUP_BUTTOCK_CONTACT       | 卧推 | 臀部要接触卧推凳                     | 臀部离开凳面           | 需要多角度  | 侧面视频检测髋/臀区域和凳面距离。宽松衣服会干扰                               |
| BP_FEET_FLAT                   | 卧推 | 脚必须平放在地面。脚可以移动，但仍要保持平放       | 脚离地，或脚没有保持平放     | 需要多角度  | 需要看到脚底和地面。正面 + 侧面更可靠                                   |
| BP_FEET_ON_BENCH_SETUP         | 卧推 | 设置动作时脚不能放到卧推凳上               | 设置时脚踩在凳上         | 需要多角度  | 识别脚部与 bench bbox 是否重叠。需要完整画面                           |
| BP_GRIP_THUMB_AROUND           | 卧推 | 手、拇指、手指要完全握住杠，卧推要求拇指环握       | 没有环握，或握法不符合规则    | 需要多角度  | 需要手部近景。普通视频通常无法可靠判断                                    |
| BP_GRIP_WIDTH_81CM             | 卧推 | 双手食指间距不能超过 81 cm             | 握距超过 81 cm       | 需要多角度  | 需要识别 81 cm 标记和食指位置。一般比赛视频很难自动判断                        |
| BP_REVERSE_GRIP                | 卧推 | IPF 禁止反握卧推                   | 使用反握             | 需要多角度  | 需要手腕和手掌方向。普通远景很难判断                                     |
| BP_START_SIGNAL                | 卧推 | 运动员要等 “Start” 口令后下放杠铃        | 口令前开始下放          | 需要音频   | 识别 “Start” 时间点。检测 bar_y 开始下降的时间。如果早于口令，则 fail          |
| BP_START_LOCKED_ELBOWS         | 卧推 | Start 前，手臂要伸直且肘锁定            | Start 前肘没有锁定     | 可自动判断  | 在 Start 前检测左右肘角。低于锁定阈值则 fail 或 uncertain               |
| BP_BAR_TO_CHEST_OR_ABDOMEN     | 卧推 | 杠铃必须下放到胸部或腹部区域               | 杠铃没有碰到胸部或腹部区域    | 可自动判断  | 用杠铃点和躯干区域距离判断。若最低点仍明显离开躯干，则 fail                       |
| BP_BAR_NOT_TO_BELT             | 卧推 | 杠铃不能碰腰带                      | 杠铃接触腰带           | 需要多角度  | 需要检测腰带区域。遮挡严重，通常只能标记 possible_belt_contact             |
| BP_MOTIONLESS_ON_CHEST         | 卧推 | 杠铃在胸腹区域要静止后才能 Press          | 杠铃没有明显停顿         | 可自动判断  | 在胸部最低点附近计算速度。若速度接近 0 的时间少于阈值，则 fail 或 uncertain        |
| BP_PRESS_SIGNAL                | 卧推 | 运动员要等 “Press” 口令后上推          | Press 口令前开始上推    | 需要音频   | 识别 “Press” 时间点。检测 bar_y 开始上升时间。如果早于口令，则 fail           |
| BP_ELBOW_DEPTH                 | 卧推 | 杠铃到底部时，双侧肘关节下侧要低于或等于各自肩关节上表面 | 任意一侧肘部没有降到要求高度   | 需要多角度  | 正面或头侧画面更可靠。比较 elbow_y 与 shoulder_y。若角度不合适，输出 uncertain |
| BP_NO_POSITION_CHANGE          | 卧推 | 选定卧推姿势不能改变                   | 头、肩或臀在动作中抬起      | 需要多角度  | 分别跟踪头、肩、臀与 bench bbox 的距离。接触关系难判断，建议保守                 |
| BP_NO_HAND_LATERAL_MOVEMENT    | 卧推 | 手不能在杠上横向移动                   | 动作中手在杠上横向滑动      | 需要多角度  | 需要检测手部与杠铃标记。普通视频不稳定                                    |
| BP_NO_HEAVING_OR_SINKING       | 卧推 | 杠铃静止后，不能把杠压进胸腹来借力            | 停顿后出现明显下沉，并用于反弹  | 只能人工判断 | 系统可检测停顿后 bar_y 继续下降，但是否“借力”需要人工复核                      |
| BP_NO_UPPER_BODY_THRUST        | 卧推 | 不能用上身顶杠启动上推                  | 胸腹或上身主动顶起杠铃      | 只能人工判断 | 可以检测胸部上移，但是否属于违规 thrust 需要人工判断                         |
| BP_NO_DOWNWARD_PRESS           | 卧推 | 上推过程中，整根杠铃不能下沉               | Press 后杠铃整体向下移动  | 可自动判断  | 从 Press 后到 lockout_frame，检测 bar_y 是否出现明显反向下降           |
| BP_FINISH_LOCKED_ELBOWS        | 卧推 | 完成时双肘要锁定                     | 完成时肘没有锁定         | 可自动判断  | 计算 lockout_frame 的左右肘角。低于锁定阈值则 fail                    |
| BP_RACK_SIGNAL                 | 卧推 | 运动员要等 “Rack” 口令后回架           | Rack 口令前回架       | 需要音频   | 识别 “Rack” 时间点。检测杠铃向架子移动或下降到支架的时间                       |
| BP_SPOTTER_CONTACT             | 卧推 | 口令之间保护员不能接触杠铃或运动员来帮助完成动作     | 保护员接触并帮助完成动作     | 只能人工判断 | 检测保护员手和杠铃接触只能作为提示。是否帮助完成动作需要人工判断                       |
| BP_FEET_TOUCH_BENCH_OR_SUPPORT | 卧推 | 脚不能接触卧推凳或支架                  | 脚碰到凳子或支架         | 需要多角度  | 检测脚部关键点与 bench/rack bbox 是否重叠                          |
| BP_BAR_REST_SUPPORT_CONTACT    | 卧推 | 不能故意让杠铃接触支架来使动作更容易           | 杠铃故意碰支架借力        | 只能人工判断 | 系统可以检测 barbell 和 rack bbox 接触，但“故意”和“使动作更容易”需要人工判断     |
| BP_GENERAL_COMPLIANCE          | 卧推 | 必须符合卧推动作描述中的所有要求             | 出现规则表外但违反动作描述的问题 | 只能人工判断 | 保留人工复核入口                                               |

# 三、硬拉 Deadlift 规则表

IPF 规则要求运动员面对平台前方，双手握住杠铃，把杠铃拉起直到站直。完成时膝盖要锁定，肩要后收。主裁只有在杠铃静止、运动员处于明显完成姿势后，才给 “Down” 口令。开始拉起后，在达到最终站直锁膝姿势前，杠铃不能下沉。IPF 规则也说明，如果肩后收时杠铃有轻微下沉，这不应该作为失败原因。

| rule_id                          | 动作 | IPF 规则含义                       | 失败条件                            | 自动化等级  | Codex 判断思路                                                    |
| -------------------------------- | -- | ------------------------------ | ------------------------------- | ------ | ------------------------------------------------------------- |
| DL_ATTEMPT_START                 | 硬拉 | 杠铃有任何上升或主动尝试上升，就算开始试举          | 杠铃开始上升后，再出现违规动作                 | 可自动判断  | 检测 bar_y 第一次持续上升的帧，作为 lift_start_frame                        |
| DL_NO_DOWNWARD_BEFORE_FINISH     | 硬拉 | 完成前杠铃不能下沉                      | 杠铃在到达最终位置前出现向下移动                | 可自动判断  | 从 lift_start_frame 到 lockout_frame 检测 bar_y 曲线。若出现明显下降，则 fail |
| DL_FINAL_ERECT                   | 硬拉 | 完成时必须站直                        | 完成时躯干没有直立                       | 可自动判断  | 计算肩、髋、膝相对位置和躯干角度。若仍明显前倾，则 fail 或 uncertain                    |
| DL_SHOULDERS_BACK                | 硬拉 | 完成时肩要后收                        | 完成时肩没有后收                        | 需要多角度  | 侧面比较肩点与杠铃垂直投影。IPF 图示要求三角肌前束在杠铃投影线后方                           |
| DL_DELTOID_BEHIND_BAR_PROJECTION | 硬拉 | 完成时三角肌前束应在杠铃垂直投影线后方            | 肩部位置没有达到规则图示要求                  | 需要多角度  | 需要高质量侧面。检测 shoulder_x 与 bar_x 的相对关系。普通视频只能估计                  |
| DL_FINISH_KNEES_LOCKED           | 硬拉 | 完成时膝盖要锁定                       | 完成时膝角明显弯曲                       | 可自动判断  | 在 lockout_frame 计算左右膝角。低于锁定阈值则 fail                           |
| DL_BAR_ON_THIGHS_SUPPORT         | 硬拉 | 不能把杠铃支撑在大腿上完成动作                | 杠铃被大腿支撑，也就是 hitching/supporting | 只能人工判断 | 系统可以检测杠铃贴近大腿且多次停顿，但是否“支撑”很难自动证明                               |
| DL_BAR_EDGES_UP_THIGH            | 硬拉 | 如果杠铃沿大腿向上，但没有被支撑，不应判失败         | 杠铃只是擦着大腿上移时，不应自动判失败             | 只能人工判断 | 这是反向保护规则。系统不要因为杠铃贴腿就直接 fail                                   |
| DL_FOOT_MOVEMENT                 | 硬拉 | 完成前不能前后移动脚，也不能横向移动。脚掌和脚跟之间摇动允许 | Down 口令前脚步移动                    | 需要多角度  | 跟踪左右脚关键点。正面看横向移动，侧面看前后移动                                      |
| DL_DOWN_SIGNAL                   | 硬拉 | 运动员必须等 “Down” 口令后下放            | Down 口令前下放杠铃                    | 需要音频   | 识别 “Down” 时间点。检测 bar_y 开始下降时间。如果早于口令，则 fail                   |
| DL_CONTROLLED_RETURN             | 硬拉 | 下放时必须双手控制杠铃回到平台                | 运动员松手，让杠铃从手中掉下                  | 可自动判断  | Down 后检测手腕与杠铃距离是否快速分离，以及杠铃是否自由落体式下降                           |
| DL_RELEASE_FROM_PALMS            | 硬拉 | 不能在回到平台前从手掌中释放杠铃               | 杠铃落地前，双手已经脱离杠铃                  | 可自动判断  | 检测 wrist 点和 barbell 点距离。如果杠铃未到地面但手已经离杠，则 fail                 |
| DL_FOOT_AFTER_DOWN_ALLOWED       | 硬拉 | Down 口令后脚步移动不算失败               | Down 后脚移动不能作为失败原因               | 需要音频   | 如果检测到脚步移动，先判断是否发生在 Down 后。Down 后不要 fail                       |
| DL_GENERAL_COMPLIANCE            | 硬拉 | 必须符合硬拉动作描述中的所有要求               | 出现规则表外但违反动作描述的问题                | 只能人工判断 | 保留人工复核入口                                                      |

程序不能只输出 `good_lift` 或 `no_lift`。程序应输出四种结果：

```yaml
decision_enum:
  - good_lift_likely
  - no_lift_likely
  - uncertain_need_human_review
  - insufficient_video_quality
```

程序逻辑的建议写法：

```python
def make_final_decision(rule_results):
    failed_rules = [r for r in rule_results if r["status"] == "fail"]
    uncertain_rules = [r for r in rule_results if r["status"] == "uncertain"]

    if failed_rules:
        return {
            "decision": "no_lift_likely",
            "failed_rules": failed_rules,
            "need_human_review": any(
                r["auto_level"] in ["需要多角度", "只能人工判断"] for r in failed_rules
            )
        }

    if uncertain_rules:
        return {
            "decision": "uncertain_need_human_review",
            "uncertain_rules": uncertain_rules,
```
